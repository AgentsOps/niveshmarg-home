# Visual Strategy Builder & Live Telemetry

The **Visual Strategy Builder** is a 100vw × 100vh interactive Directed Acyclic Graph (DAG) canvas that allows traders, quants, and researchers to design, configure, inspect, and evaluate algorithmic trading strategies visually without writing boilerplate code.

Access the Visual Strategy Builder for any strategy by navigating to:
```text
http://localhost:8000/strategy/builder/<strategy_id>/
```

Or click **"New Strategy in Visual Builder"** from the Django Admin Strategies list. This opens `/strategy/builder/new/` with a template loaded but **unsaved**; the first **Save** creates the strategy. The admin **"Sync Starter Templates"** action only adds templates that are missing.

![Strategies Admin List](screenshots/08_strategies_admin_list.png)

---

## 1. Canvas Interface Overview

The builder interface is divided into four main sections:

![Visual Strategy Builder Canvas](screenshots/02_strategy_builder_canvas.png)

1. **Top Control Bar**:
   - **Strategy Name & Version**: Editable title and version badge.
   - **Starter Templates Dropdown**: Instantly load pre-built quantitative strategies (e.g., EMA Pullback, SMC Order Block & FVG, Crypto Trend Rider, Bollinger Breakout).
   - **Auto-layout Button**: Arranges nodes left-to-right in topological columns that follow the wiring.
   - **Canvas / JSON Switcher**: View and edit the underlying canonical JSON definition in real time.
   - **Live Preview Button (`btn-toggle-preview`)**: Toggles real-time DAG evaluation with animated execution telemetry.
   - **Run Backtest**: Saves the strategy first, then opens a new Backtest Run form in admin for it; saving that form queues the run on the Celery worker.
   - **Save Strategy**: Validates DAG completeness and persists the strategy.

2. **Left Node Palette**:
   Categorized draggable blocks organized into Market & Sizing, Indicators, Smart Money Concepts, Conditions, Logic Operators, Entries, Exits, and Utility (Debug Probe).

3. **Center Graph Canvas**:
   Interactive SVG and DOM canvas supporting smooth panning (drag canvas), zooming (mouse wheel / zoom controls), multi-port wire connections, and snapping.

4. **Right Node Parameter Inspector**:
   Clicking any node opens a slide-over drawer to configure periods, thresholds, risk percentages, and inspect runtime telemetry.

## 2. Complete Catalog of Strategy Nodes

Every node type is declared once in `apps/strategies/nodes/` (a `NodeSpec` with typed ports, parameters, how it computes and how it is drawn). The palette, the inspector, the validator, the engine and the preview all read that registry, and so does this section: it is generated by `python manage.py export_node_catalog` and a test fails when it drifts. Strategies saved under schema 1.x are upgraded on read (namespaced node ids, one Compare node with an `operator`).

_208 node types in 18 groups, generated from the node registry (schema 2.0.0). Port types: **candles** (candles), **series** (a number series), **signal** (a true/false signal), **position** (a position), **exit** (an exit rule), **any** (anything). A wire may only join an output to an input that accepts its type; incompatible wires and loops are refused on the canvas and again on save._

### Market and sizing

- **Market & Timeframe** (`market.data`): The instrument and bar size the strategy trades. Every other node reads these candles; a backtest or runner loads this symbol at this timeframe.
  - Inputs: none. Outputs: `candle_out` (candles).
  - Parameters: `symbol` (symbol; default `NSE:NIFTY50-INDEX`): Canonical instrument id, e.g. NSE:NIFTY50-INDEX or DELTA:BTCUSD-CRYPTO.; `timeframe` (timeframe; default `15m`; 10 choices).
- **Position Sizing** (`risk.position_size`): How many units each entry buys. Risk mode sizes so that the stop loses the given percent of equity; fixed capital commits a set amount per trade. Capped by cash, max capital, and optional `max_stop_pct` (rejecting wide stops).
  - Inputs: `signal_in` (signal). Outputs: `order_out` (signal).
  - Parameters: `sizing_type` (enum; default `PERCENT_EQUITY`; choices `PERCENT_EQUITY`, `RISK_PERCENT`, `FIXED_CAPITAL`, `FIXED_QUANTITY`, `NOTIONAL_PERCENT`); `risk_percent` (float; default `1.0`; range 0.01 to 100.0; %): Percent of equity lost if the stop is hit.; `max_capital` (float; default `100000.0`; range 0.0 to …; ₹): Never commit more than this to one trade.; `quantity` (int; default `1`; range 1 to 1000000): Units per trade in the fixed-quantity mode (rounded down to whole lots).; `notional_percent` (float; default `10.0`; range 0.01 to 100.0; % of equity): Position value per trade in the notional mode.; `max_stop_pct` (float; default `0.0`; range 0.0 to 50.0; %): 0 disables the cap. Skips any trade whose stop distance exceeds this % of entry price (e.g. 5.0 for Swing CNC)..
- **Constant** (`market.constant`): A flat series holding one number, for comparing or combining with other series.
  - Inputs: none. Outputs: `value` (series).
  - Parameters: `value` (float; default `0.0`).
- **Price** (`market.price`): One series out of the candles: open, high, low, close, volume or a typical price such as (H+L)/2.
  - Inputs: `candle_in` (candles). Outputs: `value` (series).
  - Parameters: `source` (source; default `close`; choices `close`, `open`, `high`, `low`, `hl2`, `hlc3`, `ohlc4`).
- **Higher Timeframe** (`market.higher_timeframe`): Rolls the strategy's bars up into a higher timeframe. Indicators wired to it compute on those bars, and each base bar reads the last higher bar that had closed, never one still forming. NSE bars align to the 09:15 session grid, crypto to UTC.
  - Inputs: `candle_in` (candles). Outputs: `candle_out` (candles).
  - Parameters: `timeframe` (timeframe; default `1h`; 10 choices).
- **Benchmark Instrument** (`market.benchmark`): Candles of another instrument (by default the Nifty 50 index) at the strategy's timeframe, lined up with the strategy's bars: each bar reads the benchmark bar that started with it, or the last one before it when the benchmark has a gap, never a later bar. Indicators wired to it compute on the benchmark's bars, for market-regime filters (Nifty above its 200-day average) and relative strength (the stock's close over the benchmark's). Read from the warehouse, so the benchmark's history must be stored; without it every value is missing and conditions on it never pass.
  - Inputs: none. Outputs: `candle_out` (candles).
  - Parameters: `symbol` (symbol; default `NSE:NIFTY50-INDEX`): Canonical id, e.g. NSE:NIFTY50-INDEX or NSE:NIFTYBANK-INDEX..
- **Risk Guard** (`risk.guard`): Per-strategy limits that stop new entries for the rest of the IST day: a maximum number of trades, a number of consecutive losses, or a realized loss as a percent of the day's starting equity. Open positions keep their exits; the runner's own daily-loss halt remains the outer limit. Needs no wires.
  - Inputs: none. Outputs: none.
  - Parameters: `max_trades_per_day` (int; default `3`; range 0 to 1000): 0 switches the rule off.; `max_consecutive_losses` (int; default `0`; range 0 to 100): 0 switches the rule off.; `daily_loss_limit_pct` (float; default `0.0`; range 0.0 to 100.0; %): 0 switches the rule off..

### Indicators

- **EMA** (`indicator.ema`): Exponential moving average of the chosen price over `period` bars (TA-Lib EMA, SMA-seeded). Reacts faster than an SMA of the same period.
  - Inputs: `candle_in` (candles). Outputs: `ema_out` (series).
  - Parameters: `period` (int; default `20`; range 1 to 1000; bars); `source` (source; default `close`; choices `close`, `open`, `high`, `low`, `hl2`, `hlc3`, `ohlc4`): The price the average reads..
- **SMA** (`indicator.sma`): Simple moving average of the chosen price over `period` bars.
  - Inputs: `candle_in` (candles). Outputs: `sma_out` (series).
  - Parameters: `period` (int; default `50`; range 1 to 1000; bars); `source` (source; default `close`; choices `close`, `open`, `high`, `low`, `hl2`, `hlc3`, `ohlc4`): The price the average reads..
- **RSI** (`indicator.rsi`): Relative Strength Index of the close (Wilder smoothing), 0 to 100. Overbought and oversold levels are display hints; compare `rsi_out` against a threshold to trade them.
  - Inputs: `candle_in` (candles). Outputs: `rsi_out` (series).
  - Parameters: `period` (int; default `14`; range 1 to 1000; bars); `overbought` (float; default `70.0`; range 50.0 to 100.0); `oversold` (float; default `30.0`; range 0.0 to 50.0).
- **MACD** (`indicator.macd`): Moving Average Convergence Divergence: fast EMA minus slow EMA, its signal EMA, and their difference as a histogram. TA-Lib seeding: the first slow + signal - 2 bars are warm-up.
  - Inputs: `candle_in` (candles). Outputs: `macd_line` (series), `signal_line` (series), `histogram` (series).
  - Parameters: `fast` (int; default `12`; range 1 to 500; bars); `slow` (int; default `26`; range 2 to 1000; bars); `signal` (int; default `9`; range 1 to 500; bars).
- **Bollinger Bands** (`indicator.bollinger`): SMA of the close with bands `std_dev` standard deviations above and below it.
  - Inputs: `candle_in` (candles). Outputs: `upper` (series), `middle` (series), `lower` (series).
  - Parameters: `period` (int; default `20`; range 1 to 1000; bars); `std_dev` (float; default `2.0`; range 0.1 to 10.0).
- **ATR** (`indicator.atr`): Average True Range (Wilder): the typical bar range in price units. Wire it into the stop node; it is also the default stop distance when no ATR is wired.
  - Inputs: `candle_in` (candles). Outputs: `atr_out` (series).
  - Parameters: `period` (int; default `14`; range 1 to 1000; bars).
- **SuperTrend** (`indicator.supertrend`): SuperTrend band from ATR: `trend_out` is +1 while price holds above the lower band and -1 below the upper band; `band_out` is the band in force, usable as a trailing level.
  - Inputs: `candle_in` (candles). Outputs: `trend_out` (series), `band_out` (series).
  - Parameters: `period` (int; default `10`; range 1 to 1000; bars); `multiplier` (float; default `3.0`; range 0.1 to 20.0; x ATR).
- **VWAP** (`indicator.vwap`): Volume-weighted average price, reset at each session's first bar (IST). Undefined, so never a signal, on instruments that report no volume such as spot indices.
  - Inputs: `candle_in` (candles). Outputs: `vwap_out` (series).
  - Parameters: `anchor` (enum; default `SESSION`; choices `SESSION`).
- **Opening Range** (`indicator.opening_range`): The high and low of each session's first `minutes` (09:15 IST open), known once the range's last bar has closed and held for the rest of that session only. `or_direction` is +1 when the range closed above its open and -1 below, and `or_close` its last close; `or_rvol` is the range's volume over its median in the previous `rvol_sessions` sessions, and `bar_rvol` each bar's volume over the same time slot's median (so opening bars are not compared with quiet afternoon bars). Zero volume counts as missing data. `breakout` fires on the first close above the high for longs (below the low for shorts), and with `direction_filter` only in the direction the range closed. Intraday bars only.
  - Inputs: `candle_in` (candles). Outputs: `or_high` (series), `or_low` (series), `or_close` (series), `or_direction` (series), `or_rvol` (series), `bar_rvol` (series), `breakout` (signal).
  - Parameters: `minutes` (int; default `15`; range 1 to 375; minutes): Never shorter than one bar: a 15-minute range on 1h bars is the first hour.; `rvol_sessions` (int; default `14`; range 2 to 250; sessions); `direction_filter` (bool; default `True`): Longs only after an up range, shorts only after a down range..
- **Keltner Channels** (`indicator.keltner`): A moving average of the close with bands `multiplier` ATRs above and below it.
  - Inputs: `candle_in` (candles). Outputs: `upper` (series), `middle` (series), `lower` (series).
  - Parameters: `period` (int; default `20`; range 1 to 1000; bars); `atr_period` (int; default `10`; range 1 to 1000; bars); `multiplier` (float; default `2.0`; range 0.1 to 20.0; x ATR); `ma_type` (enum; default `EMA`; choices `EMA`, `SMA`, `WMA`, `DEMA`, `TEMA`, `KAMA`).
- **Donchian Channels** (`indicator.donchian`): Highest high and lowest low of the last `period` bars (the current bar included) and their midpoint.
  - Inputs: `candle_in` (candles). Outputs: `upper` (series), `middle` (series), `lower` (series).
  - Parameters: `period` (int; default `20`; range 1 to 1000; bars).
- **Heikin-Ashi** (`indicator.heikin_ashi`): Heikin-Ashi candle values: smoothed open/high/low/close that make trends easier to read. Compare `ha_close` against `ha_open` for the candle colour.
  - Inputs: `candle_in` (candles). Outputs: `ha_open` (series), `ha_high` (series), `ha_low` (series), `ha_close` (series).
- **Pivot Points** (`indicator.pivot_points`): Classic floor-trader pivots from the previous session's high, low and close, constant through the session: pivot, R1 to R3 and S1 to S3. NaN during the first session.
  - Inputs: `candle_in` (candles). Outputs: `pivot` (series), `r1` (series), `s1` (series), `r2` (series), `s2` (series), `r3` (series), `s3` (series).
- **Relative Volume** (`indicator.relative_volume`): The bar's volume divided by the average volume of the previous `period` bars; 2.0 means twice the usual activity. NaN on instruments without volume.
  - Inputs: `candle_in` (candles). Outputs: `value` (series).
  - Parameters: `period` (int; default `20`; range 1 to 1000; bars).

### Exits

- **Target** (`exit.target`): Take profit: an R multiple of the stop distance (default), a percent or points from the entry, or a wired level such as a swing high or the previous day's high. Fills at its price; when a bar touches both the stop and the target, the stop wins.
  - Inputs: `position_in` (position), `level_in` (series, optional). Outputs: `exit_out` (exit).
  - Parameters: `mode` (enum; default `R`; choices `R`, `PERCENT`, `POINTS`, `SERIES`); `rr_ratio` (float; default `2.0`; range 0.1 to 50.0; R); `percent` (float; default `2.0`; range 0.01 to 100.0; %); `points` (float; default `100.0`; range 0.01 to …).
- **Stop Loss** (`exit.stop`): Protective stop: an ATR multiple (default, using the ATR wired into `atr_in` or a 14-period ATR), a percent or points from the entry, or a wired level such as a swing low or an order-block edge pushed `buffer_pct` further away. Fills at market with slippage; a gap through it fills at the open. No trade is taken when a wired level is missing. An ATR stop is never narrower than 0.5% of the entry price: on fast bars whose ATR is smaller than that, the stop is effectively a fixed stop, and the backtest log says how many entries it affected.
  - Inputs: `position_in` (position), `atr_in` (series, optional), `level_in` (series, optional). Outputs: `exit_out` (exit).
  - Parameters: `mode` (enum; default `ATR`; choices `ATR`, `PERCENT`, `POINTS`, `SERIES`); `atr_multiplier` (float; default `1.5`; range 0.1 to 20.0; x ATR); `percent` (float; default `1.0`; range 0.01 to 100.0; %); `points` (float; default `50.0`; range 0.01 to …); `buffer_pct` (float; default `0.0`; range 0.0 to 10.0; %): Pushes a wired level this much further from the entry..
- **Trailing Stop** (`exit.trailing_stop`): Moves the stop behind the close by an ATR multiple or a percent, only ever towards profit, once the trade is `activation_r` R in profit (0 trails from the first bar). The stop is updated at each bar's close and applies from the next bar.
  - Inputs: `position_in` (position), `atr_in` (series, optional). Outputs: `exit_out` (exit).
  - Parameters: `mode` (enum; default `ATR`; choices `ATR`, `PERCENT`); `atr_multiplier` (float; default `2.0`; range 0.1 to 20.0; x ATR); `percent` (float; default `1.0`; range 0.01 to 50.0; %); `activation_r` (float; default `0.0`; range 0.0 to 20.0; R).
- **Break-Even** (`exit.break_even`): Moves the stop to the entry price once the trade closes `trigger_r` R in profit, so a winner cannot turn into a loser (charges aside).
  - Inputs: `position_in` (position). Outputs: `exit_out` (exit).
  - Parameters: `trigger_r` (float; default `1.0`; range 0.1 to 20.0; R).
- **Time Exit (Square-off)** (`exit.time`): Flattens the position and stops new entries from this IST time on intraday strategies (never later than the platform square-off), and optionally closes any position at the next open after it has been held `max_bars` bars (0 = off).
  - Inputs: `position_in` (position). Outputs: `exit_out` (exit).
  - Parameters: `exit_time` (time; default `15:15`): HH:MM in IST.; `max_bars` (int; default `0`; range 0 to 10000; bars).
- **Exit on Condition** (`exit.signal`): Closes the position at the next bar's open when the wired condition is true, evaluated for the closing side (a long exits on a SELL-side signal).
  - Inputs: `position_in` (position), `condition_in` (signal). Outputs: `exit_out` (exit).

### Utility

- **Debug Probe (Watch)** (`util.probe`): Shows whatever is wired into it in the preview and passes it through unchanged, so a value or signal can be watched mid-graph.
  - Inputs: `probe_in` (any). Outputs: `probe_out` (any).
  - Parameters: `label` (string; default `Debug Probe`); `log_mode` (enum; default `ALL_BARS`; choices `ALL_BARS`, `SIGNALS_ONLY`).
- **Strategy Note** (`util.note`): Place sticky notes, annotations, trading rules, or checklists directly on the strategy canvas.
  - Inputs: none. Outputs: none.
  - Parameters: `title` (string; default `Strategy Note`): Header title for the note card; `text` (text; default ``): Content, trading rules, or checklist; `color` (enum; default `amber`; choices `amber`, `indigo`, `emerald`, `slate`): Card theme color on canvas.

### Math

- **Math (A, B)** (`math.binary`): Combines two series bar by bar: add, subtract, multiply, divide, min, max or percent difference. Candles are read by their close. Division by zero gives NaN.
  - Inputs: `a` (series or candles), `b` (series or candles). Outputs: `value` (series).
  - Parameters: `op` (enum; default `SUBTRACT`; choices `ADD`, `SUBTRACT`, `MULTIPLY`, `DIVIDE`, `MIN`, `MAX`, `PERCENT_DIFF`).
- **Transform** (`math.unary`): Transforms one series: absolute value, negate, the value N bars ago, the change or percent change over N bars, a rolling z-score, or the natural log.
  - Inputs: `a` (series or candles). Outputs: `value` (series).
  - Parameters: `op` (enum; default `PERCENT_CHANGE`; choices `ABS`, `NEGATE`, `SHIFT`, `PERCENT_CHANGE`, `CHANGE`, `ZSCORE`, `LOG`); `n` (int; default `1`; range 1 to 1000; bars).
- **Rolling Window** (`math.rolling`): Highest, lowest, mean, standard deviation or sum of a series over the last `period` bars, the current bar included.
  - Inputs: `a` (series or candles). Outputs: `value` (series).
  - Parameters: `op` (enum; default `HIGHEST`; choices `HIGHEST`, `LOWEST`, `MEAN`, `STD`, `SUM`); `period` (int; default `20`; range 1 to 1000; bars).

Clicking the **"• Live Preview"** button connects to the ASGI WebSocket endpoint (`/ws/builder/preview/`). The backend executes the strategy against historical candle data with the exact same simulator logic used in production, returning rich step-by-step DAG telemetry:

![Live Preview Active with Telemetry](screenshots/03_strategy_builder_preview.png)

### Visual Execution Flow Features

1. **Sequential DAG Animation**:
   Nodes transition to running states sequentially in topological DAG order.
2. **Execution Glow & Pulsing**:
   - Evaluating nodes pulse with an emerald cyan glow (`node-running-glow`).
   - Triggered/passing condition nodes pulse in vibrant emerald green (`node-triggered-glow`).
3. **Status Badges**:
   Each node card header displays its real-time state:
   - `FEEDING`: Market data supplying candle feeds.
   - `ACTIVE`: Indicators calculating series.
   - `TRUE (PASS)` / `FALSE`: Condition nodes indicating trigger states.
   - `LISTENING`: Entry/Exit nodes waiting for conditions to align.

   SVG connecting wires become dashed and animate forward (`wire-active-flow`), visually illustrating data flowing from market data into indicators and logic gates.
5. **Port-Level Inline Badges**:

   - **Output Ports**: Show the resulting calculated value (e.g., `₹24,445.49`, `₹91.90`, `TRUE`).
6. **Inline Telemetry Summary Box**:
   Located at the bottom of each node, displaying step number and formula details without affecting connection port coordinates.

   The **"Node I/O: ON/OFF"** button in the preview drawer allows toggling canvas badges on and off for clean presentation.

## 7. Saving & Running Backtests

1. **Auto-Validation**: The builder continuously checks for disconnected input ports, incompatible port types, cycles, or missing exit rules. When valid, the top status pill turns green: `Ready & Connected`.
2. **Save**: Click **"Save Strategy"** to persist the graph. Editing a saved strategy bumps its version; older backtest runs are then marked stale.
3. **One-Click Backtest**: Click **"Backtest"** in the top navigation bar; the strategy is saved first and a new Backtest Run form opens (prefilled with the strategy). Saving it queues the run on the Celery worker (it stays `PENDING` if the worker is not running).
